# Previous Hyprland colours (snapshot 2026-08-01, before the green-steel theme)

Full copies of the original files sit next to this one. To roll back completely:

    cp ~/.config/hypr/theme/backups/2026-08-01-purple-cyan/general.conf ~/.config/hypr/hyprland/
    cp ~/.config/hypr/theme/backups/2026-08-01-purple-cyan/rules.conf   ~/.config/hypr/hyprland/
    hyprctl reload

Note: that also reverts the G2 / squircle corner change (rounding 15, rounding_power 4.0)
back to rounding 10, rounding_power 2.

## The values, for reference

`hyprland/general.conf`, `general {}`:

    col.active_border   = rgba(AD44CCee) rgba(F089DEee) 45deg   # purple -> pink
    col.inactive_border = rgba(302D3Eaa) rgba(595959aa) 45deg   # dark grey-violet -> grey

`hyprland/general.conf`, `decoration { shadow {} }`:

    color = rgba(1a1a1aee)                                      # neutral near-black

`hyprland/rules.conf`, per-window border variables:

    $floating_border_active   = rgb(00d4ff)                     # cyan
    $floating_border_inactive = rgb(005577)
    $pinned_border_active     = rgb(B98578)                     # coral / warm
    $pinned_border_inactive   = rgb(5a3c3c)

## Not touched by the theme change

- `scheme/current.conf` is regenerated by caelestia from the wallpaper. A copy is saved
  here as `scheme-current.conf` (the pink/rose scheme that was live on 2026-08-01).
- `theme/mocha.conf` is the Catppuccin palette. It is not sourced by `hyprland.conf`,
  so it was inert already. Left alone.
